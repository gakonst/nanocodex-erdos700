## Objective

Start again from the exact valuation identity for

```
D_n(k) = n / gcd(n, binomial(n,k))
```

and the original Part (iii) quantifiers. Find a materially different
representation or invariant. Examples of acceptable changes include:

- a generating-function or polynomial identity controlling many primes at one
  coefficient;
- a p-adic/adelic product-formula invariant;
- entropy or compression applied to the complete binomial row rather than
  marginal Lucas shadows;
- a minimal-counterexample descent that changes `n`;
- an additive-combinatorial energy with an exact arithmetic transference
  theorem;
- a spectral/representation-theoretic object whose hypotheses follow from the
  common integer `n`;
- a new counterexample architecture with a genuine all-index certificate.

These are prompts, not required directions. Workers should invent better ones.

Every worker must:

1. name the precise dead-end it avoids;
2. state one quantified, independently falsifiable lemma strictly stronger
   than a reformulation of the target;
3. prove the exact implication to Part (iii) or to a counterexample;
4. attack the lemma immediately with exact small and structured tests;
5. return a proof, unbounded counterfamily, or first exact failed implication.

The lead must select only a route that changes the implication graph. A longer
argument inside DFC, boundary capture, or disjoint shadows is not success here.
