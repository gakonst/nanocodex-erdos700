# Exact-verdict campaign shortlist

Screened on 22 July 2026 using the local case corpus and failure taxonomy.
These are research targets, not claims that a bounded campaign will solve them.

## Hard gates

1. A current canonical source still describes the exact target as open.
2. Success is a finite witness, kernel proof, or independently checkable
   certificate rather than a long argument that merely looks plausible.
3. A checker can be written and frozen before paid discovery.
4. Phase one is bounded and has a concrete artifact and kill rule.
5. At least three genuinely different representations are available.
6. A successful artifact would be meaningful and separately novelty-auditable.

The first three are mandatory. This rejects famous targets whose only feedback
is model confidence, targets with mutable statements, searches where floating
feasibility is mistaken for proof, and campaigns whose verifier is generated by
the same model as the candidate.

## Ranked targets

### 1. Stretched Littlewood–Richardson negativity

Find partitions `lambda`, `mu`, and `nu`, each of length at most seven and
weight at most 30, with `|lambda| = |mu| + |nu|`, for which the polynomial
`c^(t lambda)_(t mu,t nu)` has a negative coefficient. The output is three
Python-style integer lists. [Canonical problem](https://epoch.ai/frontiermath/open-problems/stretched-lr-coefficients).

This is the first launch because it asks for a tiny exact witness, admits hive,
Ehrhart, LR-tableau, symbolic, and solver representations, and can be checked
with exact LR coefficients plus a proved degree bound. A public claim of
positivity through length four is treated only as an unverified lead; search
should focus on lengths five through seven.

### 2. Exact Ramsey number R(3,10)

The known interval is `{40,41}`. Either produce a 40-vertex triangle-free graph
with independence number at most nine, or a checkable UNSAT certificate for the
exact CNF. [Current upper-bound paper](https://arxiv.org/abs/2401.00392).

### 3. Hadamard matrix of order 668

Produce a `668 x 668` matrix over `{−1,+1}` whose exact Gram matrix is `668 I`.
Generic bit search is a no-go; a campaign survives only if it finds a
structure-reduced construction. [Canonical problem](https://epoch.ai/frontiermath/open-problems/hadamard).

### 4. Steiner system S(6,8,29)

Produce 16,965 distinct eight-subsets of a 29-element set such that every
six-subset occurs exactly once. The certificate is an explicit block list and
an independent incidence tally. [Open-problem overview](https://epoch.ai/frontiermath/open-problems/large-steiner-systems).

### 5. Erdős problem 307

Find finite sets of primes `P,Q` with `(sum 1/p)(sum 1/q)=1`. Exact
cross-multiplication, primality certificates, and a Lean instantiation form the
endpoint. It ranks fifth because known lower bounds make naive enumeration
useless. [Canonical status page](https://www.erdosproblems.com/307) and
[formal statement](https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/ErdosProblems/307.lean).

## Deliberate no-go targets

- Caccetta–Häggkvist, Collatz, RH, and similar famous proof-only targets lack a
  bounded decisive gate for this campaign.
- Existing provisional AI claims such as Erdős 421 need independent audit, not
  another discovery run.
- M23 inverse Galois is deferred until its final checker is reproducible without
  proprietary Magma.
- Floating-score arenas are harness smoke tests, not clean exact-breakthrough
  campaigns.
