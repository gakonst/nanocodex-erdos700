# Erdős 700 campaign index

This directory contains frozen research assignments: exact targets,
hypotheses to test, required evidence, and completion gates. A prompt records
what was attempted; it does not establish its own requested result.

For outcomes, use the [all-parts research map](../../docs/research-map.md),
the [canonical status](../../docs/status.md), and the detailed
[Part (iii) exploration ledger](../../docs/part-iii-exploration-map.md).

## Adding a campaign

A new prompt must:

1. quote the immutable target and its quantifier order;
2. name the no-retry constraints it escapes;
3. state one falsifiable mathematical hypothesis;
4. specify what each possible outcome changes;
5. separate finite diagnostics from asymptotic evidence;
6. define a completion artifact and evidence label;
7. reject a renamed conditional reduction as target progress.

Generated reports and telemetry stay under ignored `runs/` directories.
Promote only audited, durable conclusions into the research map and result
ledger.
