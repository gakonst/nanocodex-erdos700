# Campaign report

## Status

`verified | strong-candidate | partial | refuted | rediscovered | blocked`

## Immutable target

Include the exact target fingerprint and link to `problem.md`.

## Result

State only what the evidence supports. Separate the full target from partial or
conditional results.

## Method and route history

Summarize all attempted route families, their outcomes, decisive failures, and
the route producing the candidate.

## Execution environment

- model/mode/effort;
- prompt and all steering;
- web/search policy and sources used;
- agent topology and branch lineage;
- specialized tools and versions;
- wall time, model calls, tokens, and cost;
- human interventions.

## Verification

Report correctness, statement alignment, novelty, and attribution separately.
Link raw compiler/verifier/certificate outputs.

## Artifacts

List content hashes and reproducibility commands.

## Remaining uncertainty

Give the strongest unresolved objection and the next check that could change
the status.
