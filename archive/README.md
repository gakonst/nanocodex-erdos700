# Archive

This directory is the retained research and engineering history. It is not the
recommended entry point.

It contains:

- the Nanocodex Rust harness and its old top-level build files;
- campaign definitions, candidate packages, prompts, templates, and verifiers;
- detailed release, novelty, reconciliation, run, and session audits;
- experiments and machine-readable certificates;
- the TeX sources used to build the three PDFs at repository root;
- the old monolithic proof README and historical CI workflow.

Nothing was deleted during the public-surface cleanup. Some internal links in
historical documents preserve the topology that existed when those documents
were written. Use [`../MAP.md`](../MAP.md) for current navigation and the Git
history when reconstructing an old layout.
